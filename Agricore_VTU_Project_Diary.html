Final Entry

31 October 2026

Work Summary:
Completed the final review of the Agricore smart farming assistance platform developed from 20 July to 31 October. The system was finally built as a Progressive Web Application with a React and Vite frontend styled using Tailwind CSS, and a Python FastAPI backend serving model inference and dataset endpoints. Farmer accounts are managed through Clerk authentication with protected routing. Plant disease detection is performed by a ResNet9 convolutional neural network built in PyTorch that accepts uploaded or camera captured leaf images and returns the disease along with cause and treatment advice, supported by a symptom based questionnaire for cases where a clear photograph is not available. Crop recommendation and fertilizer advisory are provided by scikit-learn models that evaluate nitrogen, phosphorus, potassium, pH, temperature, humidity, and rainfall against ideal nutrient values per crop. Ten processed agricultural datasets covering cultivation guides, disease treatments, ideal nutrient values, crop yield, rainfall, market prices, and loan schemes are served to the interface through REST endpoints. Additional modules include the AgriBot assistant built on the Gemini API with a model fallback chain and an offline answer bank, a weather module with a three day forecast and spraying condition advisory, market price trends rendered with Recharts, a Krishi Vigyan Kendra locator built with Leaflet, a government schemes and loans section with printable application document generation, a community question forum with image upload, crop reminders, farming calculators, and a reference library. The complete interface supports six languages, namely English, Hindi, Kannada, Tamil, Telugu, and Malayalam, with text to speech playback for farmers with limited literacy. The application was packaged for Android using Capacitor and the source code was organized and published to a version controlled repository.
Hours Worked: 4
Reference Links:
Project Synopsis
Learnings / Outcomes:
Successfully delivered a working end to end smart farming platform integrating deep learning based disease detection, machine learning based crop and fertilizer advisory, generative AI assistance, and multilingual farmer support. Final testing confirmed that the backend loads both trained models on startup and that all dataset and prediction endpoints respond correctly, with the frontend rendering live advisory data across every module. Gained practical experience in full stack development, model training and deployment, dataset engineering, REST API design, internationalization, and Progressive Web Application packaging.
Blockers / Risks:
Disease prediction accuracy depends on image clarity and lighting conditions in the field. Market price data is served from a historical dataset rather than a live feed, and the chatbot depends on external API availability, for which a fallback answer bank has been provided.
Skills Used:
React.js, Vite, Tailwind CSS, Python, FastAPI, PyTorch, ResNet9, scikit-learn, Pandas, NumPy, react-i18next, Leaflet, Recharts, Clerk, Gemini API, Web Speech API, Capacitor, PWA, REST API Integration, Git, GitHub
